Measured 3D collagen: do predictions transfer?

One held-out batch of nonlinear rheology and one held-out 3D displacement field challenge the assumptions behind our collagen models.

The tests expose substantial errors. A model fitted on batch A and selected on B underpredicts batch C. On a measured collagen field, the selected elastic baseline performs worse than harmonic interpolation. These are useful limits on prediction, not evidence of a validated aging or fracture model.

Batch C stays out of fitting and selection

We fit batch A, select among a linear baseline and 25 semi-affine fiber-law candidates using batch B, then score batch C without rescaling. The common strain range is 0.005–0.19; source batch B at 2.4 mg/mL stops near 0.20. These are published average nonlinear shear-ramp curves, not raw replicate histories or oscillatory G′/G″.

The selected sphere-averaged law permits compression buckling, a linear stretching range, and exponential stiffening. It uses λs = 0.04, ds = 0.05 and a fixed d0 = 0.0025 prior, with three concentration-specific scales fitted only on A. At 1.2 mg/mL its test stress bias is −8.88 Pa. The failure to transfer batch stiffness dominates the small improvement over a linear model.

Final-position errors and coverage

4,355 valid test vectors occupy eight spatial octants; they are correlated observations within one held-out position. Primary displacement scoring weights octants equally. The source contains 240 missing vectors; 212 geometrically prescribed vectors are missing, leaving 3,385 supplied nodal constraints. Test points whose 35 µm interrogation supports overlap supplied supports were excluded before outcomes were scored.

Raw P1 strain is a volume-weighted infinitesimal-strain derivative descriptor. A post-test, non-selecting check averages displacement gradients on complete guarded 5³ neighborhoods spanning about 61 × 61 × 59 µm. It leaves 303 centers, with strain NRMSE 0.605 for harmonic and 0.658 for elasticity. The larger 9³ averaging stencil has no eligible centers and is reported as unavailable. These strains derive from the same PIV observations; they are not independent ground-truth strain measurements.

The secondary displacement NRMSE uses the observed held-out field’s RMS after boundary-only translation removal. This normalization differs from the optional boundary-derived scale in the prospective protocol; it affects neither predictions nor the primary absolute-error selection.

What is open and what remains missing

Saenopy v0.7.4 public example assets supply paired measured 3D collagen images and image-derived displacement arrays. The 2024 Nature Physics paper supplies the batch A/B/C rheology source tables. Raw images and publisher spreadsheets are linked rather than redistributed in our bounded package; an explicit data redistribution license was not found inside the example ZIPs.

No openly retrieved package here links actual segmented fiber connectivity, independently applied cell forces, local strain and rheology for the exact same specimens. The imaging and bulk tests therefore remain separate. Existing inverse-model forces are never used as validation targets. The smaller organoid example is too thin for the guarded 3D holdout and is not the primary test.

The NIST DVC Challenge 2.0 provides another measured collagen inclusion dataset with an explicit repository license, separately from its synthetic collagen challenge. Its data endpoints timed out in this session, so it was not analyzed or substituted with the synthetic field.

Protocol and reproducibility

The source package preserves the prospective split, masks, input-support correction, model-selection freeze, every final outcome, numerical checks and independent audits. Nine analytic FE checks pass; free equilibrium residuals are recomputed. The material scale is unidentifiable from these homogeneous Dirichlet fields. Mesh convergence, actual collagen topology, PIV measurement-operator convolution and independent strain ground truth remain unresolved. The selected ν is a predictive candidate, not a measured tissue property.
