What this experiment can establish

Position 007 selects parameters. Position 008 is an adaptively reused benchmark: its outcomes were already examined in an earlier study. One position and its correlated octants do not support an independent-sample significance claim.

The mesh samples measured PIV displacement; it does not reconstruct collagen fiber connectivity. The directional continuum includes compressive softening and irreversible plastic lengthening as a sliding surrogate. The assumed proportional loading path is not measured. Absolute stiffness, cell force, fracture toughness, chemical aging and true crosslink sliding are not validated by this test.

Local strain is derived from the same displacement observations, not an independent ground-truth strain measurement. The wider 5³ stencil uses 303 complete guarded centers.
