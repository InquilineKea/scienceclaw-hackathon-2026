# Original and corrected archives

For the **exact corrected WordPress publication packages**, use [fracture-atlas-complete-final-f0a5034f44aa.zip](fracture-atlas-complete-final-f0a5034f44aa.zip) (includes rendered media) or [fracture-atlas-data-source-final-f0a5034f44aa.zip](fracture-atlas-data-source-final-f0a5034f44aa.zip) (the bytes embedded in the supplement). Both explicitly include final media input and its provenance audit. [Checksums, all-frame comparisons, and public recovery verification](../../collagen-network-atlas/publication/final-f0a5034f44aa/) accompany them.

Use **fracture-atlas-frozen-20261031.zip** for the finished atlas with final results and matching regenerated diagrams/animations. Its manifest covers source, numerical data, logs and figures. Historical rendering input is clearly labeled inside it.

`fracture-atlas-complete.zip` and `fracture-atlas-data-source.zip` are the original received archives, preserved unchanged. Their final numerical results were already correct, but they excluded the intermediate media-input file. That intermediate file retained older total support-reaction records. A subsequent audit established that regenerated final-model figures are byte-identical to the original full ZIP's figures; all hosted GIF bytes and all hosted PNG pixels also match. Prefer the versioned packages above when reproducing media provenance, because they include the corrected input and audit explicitly.

`public-scienceclaw-collagen-results-complete.zip` is the previously published molecular package. Additional available raw attempt files and prior GROMACS trajectory files are unpacked under collagen-molecular-pilot elsewhere in this repository.

`collagen-pilot-results.zip` is the previously downloaded and verified GROMACS baseline, not a newly executed MD study. `collagen-mechanics-explorer-with-brev-evidence.zip` is the prior explorer with an evidence panel; external dependencies and launch extensions were not executed as part of this archive update.
