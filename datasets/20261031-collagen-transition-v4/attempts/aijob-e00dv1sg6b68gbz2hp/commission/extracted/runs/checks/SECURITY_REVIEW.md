## Findings and mitigations

- **Medium supply-chain risk:** container and wheel native binaries and all transitive runtime code were not independently reverse engineered or signature-verified. Official origin, old pinned releases and matching hashes identify bytes but do not prove safety. The disposable job has no user home, browser, GitHub session, SSH agent, API keys or unrelated files mounted.
- **Medium execution risk:** the existing user-owned NumPy/PyTorch fibre model was inspected through the Batch class; the source snapshot and hash are preserved. New model, wrapper and plotting code were statically inspected and parsed. There are no model checkpoint loads, downloaded executable scripts, Git hooks, repository installers, AI-written shell dispatch or pickle deserialization. Only known reviewed wheels are installed remotely with --no-index --no-deps --no-compile; no source builds or dependency resolution occur.
- **Medium network risk:** explicit HTTPS downloads of the pinned wheels are the only required worker setup network access. The unprivileged scientific child receives a minimal environment and a Linux no-new-privileges/seccomp rule denying IPv4/IPv6 sockets. It tests that restriction and refuses execution if the restriction cannot be installed. New private output storage is the only mounted user data. The provider runtime, GPU driver and storage client remain trusted infrastructure.
- **Medium budget/retention risk:** cloud billing includes startup/shutdown and may differ from estimates; prior account usage is unrelated to this cap. A provider timeout plus shorter child watchdog bounds each submitted job. Source, results and failure logs are archived on completion; no automatic recomputation or restart. Keep cumulative job estimates below $15 and verify completion. A quota-limited private output bucket retains data and has a small separate storage charge.
- **High scientific inference risk:** these are uncalibrated mechanistic models. They cannot establish clinical resilience, real pressure tolerance, actual AGE reactions, tissue jamming, species-specific melting temperatures or measured LOX bistability. Invalid equilibria remain labelled. The thermal MD gate remains explicit.

No new local third-party execution is authorized or performed. Remote execution follows the user's global exception after this review is reported. A clean pattern scan is not proof of absence of malicious behavior; residual runtime and scientific uncertainty remains.
