# Frozen collagen raw-data preservation bundle

This lossless, uncompressed TAR combines five previously completed, frozen records: the finished 450-case network atlas; the separate storage-verification and automatic-upload-validation repetitions; the completed molecular pilot including available L4 comparison records; and the prior GROMACS pilot. The repetitions are reproducibility checks, not new independent biological evidence. No new GPU computation was performed to create this archive. No padding or fabricated raw data is included.

MEMBER_MANIFEST.json records every TAR member's byte count and SHA-256. The outer MANIFEST.json covers the complete TAR and supporting files. Existing frozen source folders remain unchanged. This archive tests and uses the automatic route for files above 95 MiB.

The network model is dimensionless, hypothetical, and two dimensional; it does not establish the toughest real collagen network under physical pressure or acceleration. Molecular fragments do not validate glucosepane, PYD, or 4-HNE reactions. The prior short GROMACS pilot is a commissioning result, not tissue-mechanics validation. Stored representative replays do not contain every internal solver step.
