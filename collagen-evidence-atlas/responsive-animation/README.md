# Selection-responsive collagen animations

Original browser-worker extension of the Collagen Evidence Atlas. Force/damage follows the crosslink laboratory's network, count, loading angle and single seed. Uniform-drag microrheology calculates a matched intact/damaged pair for the selected family, size, frequency, seed, connector density and probe angle. No cloud or paid API. Fluid-coupled fields remain exact-match saved coverage only; unsupported selections are blank with an explicit explanation.

Runtime source and scientific methods: web/ANIMATION-METHODS.md. Owning original module hashes: SOURCE-PROVENANCE.json. Security review: SECURITY.md. Independent original numerical checks: check-worker.cjs and VALIDATION.json. Raw commissioning results, including the excluded static case, are retained in checks/. The harness uses only Node builtins and original scientific modules, with no network or credentials exposed to the VM context.

Saved ensemble data and measured3D fields remain unchanged. New browser calculations are single-realization synthetic model responses, not material calibration or biological validation.

The final runtime embeds the reviewed original worker sources into network-scenes.js and starts a Blob worker. This avoids new-file CDN lookup dependencies; individual modules remain in the source bundle. Blob URLs are revoked after completion, error, cancellation or timeout.
