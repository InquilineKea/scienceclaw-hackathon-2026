# Responsive animation security and execution review

Scope: existing original ScienceClaw model.js, directional.js, aging.js and the pure numerical functions from microrheology/run.js, copied from the owning local/public project. These are original project scientific code, not a new third-party package. Read all model/aging/directional functions and the complete original micro experiment before adapting it. No installer, package manifest, transitive dependencies, hooks or external runtime. The worker imports only four local allowlisted original files. The micro adaptation removes Node fs and batch/file-writing entry points, wraps its namespace, and adds bounded connector density.

No credential access, network calls, file access, persistence, obfuscation or dynamic eval in numerical code. Worker request parameters are allowlisted and bounded. Workers are terminated on changed controls, cancellation, details closing or timeout; stale results cannot overwrite a newer selection. Residual risks: a numerical bug or slow solve remains possible; confinement does not establish model validity. All unqualified results remain labeled or excluded. The work uses native browser execution and original stdlib/Node harnesses only; no new third-party local execution or installation. No cloud resources/API spend.

The final runtime embeds the reviewed original worker sources into network-scenes.js and starts a Blob worker. This avoids new-file CDN lookup dependencies; individual modules remain in the source bundle. Blob URLs are revoked after completion, error, cancellation or timeout.
