# Hydroxyproline force-field benchmark

Reproducible comparison of published AMBER and CHARMM parameterizations of (2S,4R)-4-hydroxyproline (Hyp)
against DFT conformational energies and experimental collagen-peptide data.

Force fields: AMBER ff99SB, ff14SB, ff19SB, CHARMM36m, CHARMM36mGP (reconstructed, see below).

**Write-up:** https://humanavianaisymbiosis.wordpress.com/2026/11/22/hydroxyproline-force-field-benchmark-amber-charmm-collagen/
**Everything in one PDF:** `hyp_benchmark_appendix.pdf` (all code and every text result; binaries listed with SHA-256).

Status in one line: parameter audit, QM geometries and force-field energies complete; 37 of 73 planned DFT single points;
MD is short exploratory sampling (40-300 ps per run on 2 CPU cores), not production length. See STATUS.md.

### Third-party files included for reproducibility
* `ff/gromacs/`: AMBER force-field ports from the GROMACS source tree (share/top, LGPL-2.1, GROMACS authors).
* `ff/omff/repo/...`: two files from openmmforcefields (MIT, see `ff/omff/LICENSE-openmmforcefields`):
  the CHARMM modified-residue conversion and the AmberTools ff19SB CMAP frcmod.
* `ff/pdb_1cag_*`: PDB entry 1CAG (Bella, Eaton, Brodsky & Berman 1994), CC0 via the wwPDB.
* `ff/derived/`: files generated by `scripts/01_prepare.py` from the above and from OpenMM 8.6.1's bundled XML.

## Layout

    hypbench/            library (registry, builders, audit, QM, MD, analysis)
    scripts/01..08       pipeline steps, in order
    tests/               pytest suite (python -m pytest -q tests)
    ff/                  retrieved parameter files (+ ff/derived: generated files, never hand-edited)
    structures/          starting coordinates built from PDB 1CAG
    results/             JSON outputs (provenance, audit, QM, MM, MD statistics)
    md/                  trajectories (solute coordinates, 0.2 ps spacing) + restart state
    figs/                figures
    STATUS.md            completed vs proposed calculations (generated by scripts/09_status.py)

## Run

    pip install openmm==8.6.1 pyscf pyscf-dispersion geometric tblite rdkit mdtraj matplotlib reportlab pytest
    # ff/omff/repo holds only the two openmmforcefields files the pipeline uses; ff/gromacs the GROMACS ports
    python scripts/01_prepare.py          # derived FF files, structures, provenance hashes
    python scripts/02_audit.py            # parameter audit            -> results/audit.json
    python scripts/03_qm_geometries.py    # GFN2-xTB constrained scans -> results/qm_geometries.json
    python scripts/04_dft.py 2            # DFT single points (resumable; `04_dft.py THREADS MAXJOBS`)
    python scripts/06_mm_vs_qm.py         # MM on the QM grid          -> results/mm_energies.json
    python scripts/05_md.py dipeptide 0.3 ff99SB ff14SB ff19SB C36m C36mGP   # resumable; raise NS to extend
    python scripts/05_md.py helix 0.04 ff99SB ff14SB ff19SB C36m C36mGP
    python scripts/07_analyze.py && python scripts/08_figures.py && python scripts/09_status.py
    python scripts/10_rank.py && python scripts/11_appendix_pdf.py
    python -m pytest -q tests

Every long step is resumable: rerun the same command (or a larger NS / MAXJOBS) and it continues.
To reach production length, rerun step 05 with e.g. `dipeptide 200` and `helix 500` on a GPU
(change the platform in hypbench/md.py) and rerun steps 07-09; no other change is needed.

## Rules the code enforces

* No silent substitution. A missing template or parameter raises. OpenMM's stock ff99SB has no HYP,
  and the test suite asserts that building with it fails rather than falling back to PRO.
* No mixed families. `ffreg.load()` refuses a water model that is not on the force field's validated list.
* Derived files are generated by code, flagged `derived=True` in the registry and listed with the reason in
  results/provenance.json:
    - ff99SB HYP template: re-encoded from GROMACS amber99sb.ff (68/68 torsions verified identical)
    - CHARMM36m HYP: single residue copied verbatim from the modified-residue file
    - CHARMM36mGP: **reconstruction** (Gly/Pro/Hyp CMAP x 0.5); the authors' Zenodo files were not reachable
* The CHARMM Lennard-Jones terms are re-encoded into the standard NonbondedForce for speed only when every
  type pair in the system obeys the combining rule (no NBFIX); energy equality is unit-tested.

## Known limits (see the report and STATUS.md)

* 2 CPU cores, no GPU: MD is 200-300 ps (dipeptide) and 40 ps (triple helix) per force field. Populations with
  few pucker transitions are not converged; the helix runs are relaxation runs from the crystal structure.
* DFT energies are single points on GFN2-xTB geometries, gas phase, with psi and the hydroxyl torsion constrained.
* Hydrogen mass repartitioning (3 amu) with a 4 fs step; OpenMM potential switch (1.0-1.2 nm) for CHARMM rather
  than CHARMM's force switch.
