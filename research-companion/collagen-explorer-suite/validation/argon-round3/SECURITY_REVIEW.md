# Round 3 static security and execution review

This concrete candidate adds 33 saved-data dashboards and upgrades four existing public Sites. GCP Argon produced the new browser modules; owned integration code corrected data handling and preserved original scientific results. No new browser modules have been executed at review time.

## Inspected
All 16 non-vendor JavaScript files were parsed without execution using Node --check. New modules, imports, network calls, DOM sinks, event handlers and the static hosting paths were inspected. All data are public research outputs; array rows are mapped losslessly to their saved column names. Original ZIP archives, JSON result artifacts, mechanics original.html, architecture scientific worker and model are byte-identical to their retrieved versions. No package manifests, installers, lifecycle hooks, Git hooks, new CI execution or dependency additions are introduced. Local Three.js/OrbitControls files reuse the exact previously approved, pinned r180 assets; integrity remains verifiable from their PINNED manifest. The existing Sites workflow helper retains the previously reviewed hashes and scoped hidden-stdin credential flow; credentials are not available to candidate code.

## Findings and residual risks
- Medium: externally generated browser code can contain rendering/runtime bugs despite static review. Validate on dedicated loopback public-static folders without credentials, personal files, installations, GPU workloads or cloud VMs. No scripts may access the source checkout, shell, secrets or simulations.
- Low: Architecture inspector uses innerHTML for fixed UI templates and numeric geometry readouts. Inputs originate in the archived local numeric data; no remote HTML or executable source is inserted. Other data readouts use textContent.
- Low: local JSON fetches are same-origin, and links point to research reports. No credential-store access, telemetry, remote executable imports, dynamic evaluation, persistence, shell execution, destructive operations or network exfiltration destinations were found. This is not proof of safety or a guarantee of dependency provenance.
- Scientific reliability: counts named accepted/qualified are not automatically treated as validation gates. Explicit source qualification metadata governs filtering. Missing coordinates/forces are not fabricated; frame-specific broken bonds and original coordinates remain distinct from display magnification. Short pilots and numerical conversion checks do not establish molecular-to-network or biological validation.

## Proposed isolated validation and publication
Serve only candidate/ through a loopback HTTP server, validate desktop/mobile controls and saved values in a browser, then publish the tested static files to the existing GitHub Pages and four public Sites under existing authorization. No installation, MD, new compute or credential access by browser code. Preserve original content, models, downloads and access settings. Candidate hashes are in candidate-manifest.json; parsing receipts are in parse-checks.json. Any discovered issue must be fixed and reviewed before publication.

User AGENTS.md: “Local execution: Do not execute third-party code on my Mac until I explicitly approve it after reviewing the findings.” Earlier browser approval covered Round 2; this is a new Round 3 candidate.
