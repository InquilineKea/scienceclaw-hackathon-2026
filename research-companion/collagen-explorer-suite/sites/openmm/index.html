02 / Test system

A deliberately small calculation.

Two particles start 0.12 nm apart with zero velocities. A harmonic bond pulls them toward an equilibrium separation of 0.1 nm. The analytic starting potential energy is 0.2 kJ/mol.

The script compares the initial energies and forces on Reference and CUDA, then checks finite final coordinates and energy conservation after CUDA integration. The timestamps cover the test program; they are not a performance benchmark.

04 / Interpretation

What this establishes.

This run establishes that the environment can load OpenMM’s CUDA platform, create a context on the L4, evaluate a harmonic bond, and integrate this small system within the chosen numerical tolerances.

Scientific scope. Validation of collagen chemistry, crosslinks, binding, aging mechanisms, solvent, nonbonded interactions, PME, and long-run stability remains outside this test. A protein or tissue claim needs its own system-specific evidence.

This test saved the initial force/energy comparison and the final positions and energy. It did not save a trajectory or an energy time series.

Reproduce the captured versions

Extract the ZIP, open its root directory, and use a Linux machine with Python 3.10, the venv module, an NVIDIA GPU and a compatible driver.

python3 -m venv --without-pip .venv
curl --fail --location https://bootstrap.pypa.io/get-pip.py -o get-pip.py
.venv/bin/python get-pip.py
.venv/bin/python -m pip install --only-binary=:all: -r requirements-lock.txt
.venv/bin/python scripts/openmm_cuda_smoke.py --output results/reproduced.json

The original Bash runner resolves available OpenMM versions at rerun time. The commands above use the captured package versions. Reruns may differ within the stated numerical tolerances. See the OpenMM installation guide for CUDA platform requirements.
