# Campaign 1: statistical design and calibration audit

Prepared 2026-10-31 by the statistics specialist. Read-only review of the active protocol, data contract, 210 measured observations, prior fit/validation summary, 3D derivative checks, 1%-amplitude attempt, and 40 small-strain states. No simulation or input was changed. This report distinguishes the existing synthetic comparator from the requested measured-architecture campaign.

## Immediate decisions

1. Preserve the current synthetic four-seed sweep as a **bulk-matched sensitivity comparator**. Do not call it measured-architecture validation. It has synthetic Voronoi geometry, assumed junction locking and rupture thresholds, and an added bulk dashpot rather than a microscopic loss model.
2. Do not use the failed seed30 1%-amplitude factor for calibrated absolute results unless a separately preserved continuation/refinement passes. In `amplitude-calibration.json`, both seed30 plane records have `accepted:false`; xz maximum gradient is 1.3324e-7, above the production 1e-7 gate. The other three seeds pass their tighter amplitude tests. `stiffness.mjs` used all factors; ratios within a seed/plane cancel this scalar but absolute values need a valid calibration factor. A continuation attempt is now in progress under the main agent; this report does not presume its result.
3. Keep the Kelvin–Voigt whole-file CV mean of 0.498 labeled as **same-study model-selection cross-validation**. It helped select Kelvin–Voigt from three candidates; it is not an untouched confirmatory estimate of the selected model's performance. The dataset and the 1–10 Hz challenge have already been examined. A new holdout label does not make previously seen observations blind.
4. Use one shared set of material parameters fitted on training specimens/geometries for Campaign 1, rather than one independently chosen scale per geometry seed. Freeze these parameters before predicting held-out architectures. Per-seed scaling deliberately removes baseline architecture-dependent modulus variation, which is useful for some intervention controls but prevents testing whether measured architecture predicts that variation.

## What the existing data actually identify

There are ten frequency-sweep files, each with 21 paired G′/G″ observations: four files at 0.8 mg/mL and three each at 1.5 and 2.3 mg/mL. The primary band contains 110 observations; the high-frequency challenge contains 100. Frequencies within a file are repeated measurements, not independent material specimens. File IDs do not establish independent gel preparations, batches or donors; this limits claims to the observed same-study files. Temperature is 37°C and oscillatory shear amplitude is 1%.

The existing low-band fits identify conditional **bulk response coefficients**. They do not separately identify fiber axial rigidity, junction bending rigidity, fiber diameter, prestress, topology, nonlocal hydrodynamic drag, sliding, permeability, physical specimen volume, chemical crosslink density, AGE exposure, age in years, tensile failure strain or fracture toughness. A parallel bulk dashpot matching G″ is a phenomenological calibration; it does not demonstrate that network geometry predicts local dissipation or its treatment dependence. Likewise, a constant baseline scale cannot validate finite-strain stiffening or local-strain fields.

The selected Kelvin–Voigt model has mean whole-file primary complex NRMSE 0.498, median 0.465 and worst 1.264; its mean primary G″ NRMSE is 0.576. Its mean high-frequency complex NRMSE is 1.251 and G″ NRMSE is 6.049. These errors are substantial. SLS/fractional models have slightly worse mean primary complex CV scores but different loss predictions; carry this model-form uncertainty instead of treating Kelvin–Voigt as a physical truth. A 0.1–1 Hz window cannot establish a long-time relaxation spectrum.

## Campaign 1 inference pipeline

**Define the experimental unit before splitting.** Acquire provenance linking each 3D image volume to its gel preparation, collagen batch/donor, concentration, temperature, preparation, rheometer specimen and loading history. If several VOIs share a specimen, group them together; VOIs held out from the same gel test spatial extrapolation only. If only one material batch exists, report that limitation rather than inventing a random-donor effect. If architecture/rheology are not specimen-matched, fit at the population/distribution level and say so.

**Freeze image-derived geometry without mechanical feedback.** Use the measured volume, orientation tensor/ODF, segment-length and diameter distributions, valency/connectivity, junction-angle distribution, fiber content and their uncertainties. Preserve important joint structure: degree–length relationships, orientation–length dependence, spatial correlations, bundling/waviness, loops and boundary crossings. Matching separate marginal distributions does not identify a unique network. Segmentation, skeletonization and boundary truncation uncertainty should generate a prespecified geometry ensemble; do not choose the realization that best fits held-out mechanics. Enforce mass/volume/fiber-content consistency independently. Record imaging resolution and unresolvable crossings.

**Choose a small shared constitutive parameter set.** Start with global axial rigidity EA, bending/rotation parameter and a physically stated dissipation parameter only if available measurements can distinguish them. Use independent fibril measurements or defensible priors/fixed values for unidentifiable parameters. Fit the same parameters across training networks of a material condition. A common calibration factor is permissible; a factor recalibrated to each test specimen is not a prediction. Check sensitivity/Jacobian rank, parameter profiles and tradeoffs; if parameters are nonidentifiable, report bounded observable predictions over the admissible parameter set. The physical length/volume map must be fixed before converting model coefficients to material units.

**Use nested model choice and group holdout.** For new paired data, reserve complete specimens or batches as the confirmatory test set before any model tuning. On training data, use inner grouped CV to choose the dissipation/constitutive family and regularization. Fit only training small-amplitude G′/G″; keep held-out whole-file frequency curves, nonlinear amplitude sweeps, local strain fields and failure measurements out of parameter fitting. If data are too few for nested splits, fit the prespecified model and label all current cross-validation exploratory. Previously viewed curves can be reused for calibration and diagnostics, but not presented as new blinded validation.

**Predict observables in the actual measurement protocol.** Simulate the 1% oscillatory amplitude, frequency, stress/strain control, temperature and boundary conditions. Report first-harmonic storage/loss and higher harmonics where nonlinear response appears. For local strain, compare the same strain definition, spatial resolution, mask and registration used experimentally. For anisotropy, use the measured orientation relative to load; two shear planes are a small directional sensitivity set, not a complete elastic tensor. Do not use an additive dashpot fitted to the target curve as evidence that microscopic architecture predicts G″.

**Score without changing the fit after seeing test errors.** Use complete test-file complex NRMSE (the original normalization documented), G′ and G″ errors separately, signed residual curves, calibration/prediction interval coverage, and specimen-level errors. Compare against simple concentration-only bulk laws and affine/randomized-architecture controls. For nonlinear stiffening, prespecify onset and tangent-modulus calculations and compare full curves; for local strain, compare both registered fields and prespecified distributions/concentration statistics. Compare observed effects to segmentation and parameter uncertainty. Failed predictions remain failures; any later revision is a new version requiring a new test set for confirmatory claims.

## Seed, angle and placement analysis

The synthetic sweep has four independent generated network seeds, two correlated shear planes per seed, and one clustered center/one distributed placement per seed. The experimental unit for a topology effect is the network seed; two angles and many strain frames do not create extra independent replicates. Summarize paired clustered–distributed differences within seed and angle, then show each seed's mean and directional range. Use descriptive sign counts and ranges; with only four networks, bootstrap intervals are unstable and small p-values based on eight angles or thousands of states would be misleading. Multiple independent placement draws per skeleton are needed to separate placement realization uncertainty from network uncertainty.

At matched locking counts, measure realized number of affected angular terms, junction valency and angle/segment orientation and length distributions among selected sites. Selecting the same number of nodes does not ensure the same total number of angular constraints or same added energy capacity. Report these differences. To isolate location more narrowly, add degree/angle-count/orientation-stratified placements; keep the current unstratified arms as the original intervention, not a clean spatial-only causal estimate. Use dose-response contrasts and count-matched controls independently of fiber mass/volume/connectivity changes.

Exploratory current small-strain paired results (from the 40 accepted states; no fracture inference): at 15% locked junctions, the mean of four seed-wise two-plane clustered/distributed ratios is 0.9757, with 2/4 seeds favoring clustered. At 30%, it is 0.8847, with 1/4 favoring clustered. This demonstrates seed dependence, not a universal clustered penalty. Within-seed ratios cancel the questionable absolute amplitude scale for seed30; absolute Pa differences do not.

## Numerical and fracture reporting gates

- Keep the original free-gradient ≤1e-7 gate and finite state requirement. Also report normalized residual versus applied load/characteristic internal force, displacement change and energy decrease. The present absolute gate is in model units; it must not be described as an SI force tolerance. Check convergence after every deletion avalanche and preserve all failed starting states and attempts.
- Check derivatives, rigid-translation/gauge invariance, rotation/objectivity appropriate to the chosen periodic deformation, zero-rest energy and solver reproduction separately. Small-strain energy reproduction is useful numerical evidence but does not validate a damaged nonlinear branch or physical collagen.
- For every accepted curve calculate external work minus stored elastic energy minus explicit deletion loss minus fixed-strain relaxation loss. Require nonnegative irreversible loss within numerical tolerance and no unexplained energy generation. Prespecify ≤2% relative terminal energy imbalance (with an absolute floor near zero work) for quantitative work claims.
- Compare 100 versus 200 increments at matched strain and report stress-curve differences, first-damage strain interval, peak stress, work to peak and damage progression. A suggested quantitative gate is ≤5% difference in peak stress and work to peak, plus the energy gate above; record each endpoint's qualification separately. If a paired arm fails a gate, do not retain its favorable result while hiding the failed comparator. Abrupt events need interval/step uncertainty rather than point precision.
- A curve reaching shear0.5 without a demonstrated peak/postpeak drop is right-censored for peak/fracture claims. Report “maximum observed stress through 50% shear” and “work to 50% shear,” not toughness or failure energy. Reaching the cap does not imply complete separation. A sample that develops breaks but is still load-bearing has damage, not necessarily a macroscopic crack. Unresolved/capped arms cannot determine complete failure rankings.
- Fiber failure thresholds of10%/20%, 10× angular locking and 15%/30% selected junctions are uncalibrated intervention parameters. Lowering failure strain creates fragility by construction; separate its effect from spatial locking. Analyze interactions instead of combining all changes into an “aged” label. No phase transition, age-years mapping, chemical AGE dose, fracture toughness Gc or species strength ranking follows from these assumptions.
- Four similar-size synthetic networks are not size/RVE convergence. Add independently generated, physically density-matched volumes at several sizes and show that treatment contrasts survive size and boundary changes before a general material claim. This differs from time-step refinement.

## Deliverable claims permitted now

“Bovine low-band bulk response was used to set a conditional material scale; synthetic 3D topology and angular-locking scenarios were compared under explicitly assumed rupture laws.” This is defensible if exclusions are carried through. “Measured 3D bovine architecture predicts stiffness, dissipation, nonlinear stiffening, local strain or fracture on withheld samples” is not supported until paired structural data and untouched target measurements are acquired and passed.
